# Sasya’s Room 🛏️
A walkable 3D portfolio built with Three.js.

## Run locally
ES modules need a server (not file://):
`python3 -m http.server 8000` then open http://localhost:8000

## Edit
- `js/content.js` – bio, paper, projects, links
- `js/room.js` – all furniture (copy a line, change coordinates/colors)
- `js/flappy.js` – the PC game; add more games the same way
- `style.css` – loading screen + modal look

## Deploy (GitHub Pages)
Repo → Settings → Pages → Deploy from branch `main` / root.
